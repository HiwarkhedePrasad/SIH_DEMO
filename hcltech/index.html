STEP 4 — Priority-ranked roadmap (P0 → P3)

P0 CRITICAL — must study

  • Python basics (datatypes, lists/dicts, loops, functions, slicing, exceptions, comprehensions) — directly tested + interview language.
  • SQL/DBMS (SELECT, WHERE, JOINs, GROUP BY/HAVING, keys, constraints) — appears in OA + interview.
  • Pseudocode / output prediction (loops, operators, recursion traces) — 20 Qs in Cocubes variant.
  • Quant speed topics (%, ratio, TSD, T&W, averages, SI/CI) + Logical (series, coding-decoding, blood relation, direction, syllogism) — sectional cutoff risk.
  • Easy coding patterns (frequency map, two pointers, single traversal): palindrome, Armstrong, reverse, second-largest, count duplicates.

P1 HIGH — strong possibility

  • OOP (class/object, inheritance, polymorphism, encapsulation) — 3–5 MCQs + interview.
  • OS + Networking basics (OSI/TCP-IP, IP vs MAC, OS vs kernel, deadlock) — paper-pen evidence.
  • Verbal (synonyms, error spotting, comprehension) + Versant speaking practice.
  • Basic cloud concepts (IaaS/PaaS/SaaS, EC2/S3, Azure VMs/Blob, regions) — definitions only.

P2 MEDIUM — possible

  • Stack/queue/linked-list concepts (not deep implementation). Recursion traces. Sorting complexity table. String built-ins.
  • HR + GD prep (intro, why HCL, relocation/shifts willingness, bond).

P3 LOW — after P0–P2

  • Advanced DSA (DP, graphs, trees), system design, hands-on AWS labs, PL/SQL triggers/procedures writing. Do NOT do competitive programming — no evidence it is needed for Ascend filter.
